# 网球反应力 · Tennis Reflex

一个用 **HTML + CSS + 原生 JavaScript（Canvas）** 写的网球反应力小游戏，**零依赖**，不需要构建、不需要 npm、不需要联网，双击打开就能玩。

🔗 **在线试玩**：<https://hotsure0625.github.io/tennis-reflex/>

用手机 / 平板打开上面这个链接就能直接玩（按住屏幕左右拖动控制球拍），不用下载任何文件。

## 玩法

- 页面显示一个简化网球场，球拍在底部
- **电脑**：用 `←` `→` 左右移动球拍
- **手机 / 平板**：按住屏幕左右拖动，球拍跟着手指走
- 网球从上方落下，接住 **+1 分**
- 漏掉一个球 **失去 1 条生命**，初始 **3 条生命**
- 每接 5 球升 1 级，**分数越高球速越快**、出球间隔越短，最高 12 级
- 生命耗尽后显示 **Game Over** 浮层和 **Restart** 按钮（也可按 `Enter` / 空格重开）

## 运行方式

### 方式一：在线试玩（最省事）

直接打开 <https://hotsure0625.github.io/tennis-reflex/>，手机、平板、电脑都能玩，由 GitHub Pages 托管。

### 方式二：单个 HTML 文件（推荐把一个文件发给别人）

直接双击 `tennis-reflex.html` 即可。所有 CSS 和 JS 都内联在这一个文件里，可以单独发给别人，对方用浏览器打开就能玩。

> 通过微信等 IM 发送时，对方需要点 `···` 选择「用其他应用打开 / 在浏览器打开」。

### 方式三：源码版本

直接双击 `index.html`（键盘 `←` `→` 或触屏拖动均可），或用任意静态服务器打开：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 文件结构

```
.
├── index.html            # 源码版页面结构
├── style.css             # 源码版样式（深色现代风格、居中布局）
├── game.js               # 源码版游戏逻辑（键盘控制）
└── tennis-reflex.html    # 单文件版：内联 CSS/JS，支持触屏 + 键盘
```

`index.html` + `style.css` + `game.js` 是分开的源码版本；`tennis-reflex.html` 是把这三者内联打包后的单文件版本，额外增加了触屏拖动支持，方便在手机上直接体验。

## 实现要点

- **渲染**：Canvas 2D 绘制球场（外框、单打边线、发球线、中线、虚线球网）与网球、球拍
- **动画**：网球旋转球缝 + 发光；球拍接球时挤压回弹 + 光晕增强；升级飘字提示；漏球红屏闪烁
- **手感**：键盘操作带平滑加减速；触屏跟随的速度上限与键盘一致，避免变成无脑自动跟随
- **细节**：适配高分屏（devicePixelRatio）、移动端动态视口高度（dvh）、防止滚动与双击缩放、切后台回来不会因大 `dt` 跳帧
